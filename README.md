# Kare Bulmaca Sözlüğü

Türkçe kare bulmacalar için ~19.700 kelime ve ipucu. [Kare Bulmaca](https://github.com/hiletmis) iOS uygulamasında kullanılır.

## Biçim

`clues.json` bir JSON dizisidir:

```json
{"a": "ARI", "c": ["Bal yapan böcek", "Temiz, saf"], "l": 0}
```

- `a`: cevap (büyük harf, Türkçe)
- `c`: ipuçları (ilki ana anlam)
- `l`: zorluk seviyesi (0 = çok yaygın … 3 = nadir)

## Kaynak ve lisans

Türkçe Vikisözlük (https://tr.wiktionary.org) maddelerinden, Vikisözlük katkıda bulunanlarının
çalışmasından türetilmiştir. Tanımlar bulmaca için kısaltılmış, filtrelenmiş ve düzenlenmiştir.
Zorluk seviyeleri [FrequencyWords](https://github.com/hermitdave/FrequencyWords) (CC BY-SA 4.0)
listesinden yararlanılarak belirlenmiştir.
